# Client Intake Questionnaire

Fill this in **before** running `/clone-website`. Every question maps to a real
file/symbol in this template — nothing here is decorative. Answer inline after
each prompt (replace the `> …` line).

---

## 1. Company / product name

- **Maps to:** `src/lib/site-metadata.ts` → `title` (regenerated by `npm run scaffold:seo`)

## 2. Tagline / one-line description

One or two sentences describing what the business does. Used for the meta
description and social-share previews.

- **Maps to:** `src/lib/site-metadata.ts` → `description`

> …

## 3. Target URL to clone

The website we will reverse-engineer 1:1 (layout, components, assets), then
adapt to your business.

- **Maps to:** input to `/clone-website <url>`

> …

## 4. Production domain

The final domain the site will live on (e.g. `https://acme.com`). Used for
canonical URLs, sitemap, and robots.txt. Write `not yet` if undecided.

- **Maps to:** `src/lib/site-metadata.ts` → `metadataBase`

> …

## 5. Site language

BCP 47 language tag for the site (e.g. `en`, `en-GB`, `fr`, `es`).

- **Maps to:** `<html lang="…">` in `src/app/layout.tsx`

> …

## 6. Brand accent color

A hex color (e.g. `#2563eb`) for primary buttons, links, and highlights — or
write `pick for me` plus a one-word feel (e.g. `trustworthy`, `energetic`,
`premium`) and we'll choose. Converted to oklch design tokens.

- **Maps to:** `--primary` / `--accent` in `src/app/globals.css`

> …

## 7. Remote image hosts

External image domains the cloned site may hotlink before assets are downloaded
locally (e.g. `images.ctfassets.net`, `cdn.sanity.io`). Comma-separated, or
`none`.

- **Maps to:** `images.remotePatterns` in `next.config.ts`

> …

## 8. Tone of voice

How the adapted copy should read (e.g. `professional`, `friendly`, `premium`,
`playful`). Guides rewriting the cloned text for your business.

- **Maps to:** copy-adaptation guidance during the post-clone pass

> …

---

## What happens next

1. You fill in the answers above and confirm the target URL.
2. We run `/clone-website <url>` → produces `docs/research/<host>/seo.json`,
   screenshots, and downloaded assets.
3. `npm run scaffold:seo` regenerates `site-metadata.ts`, `robots.ts`,
   `sitemap.ts`, and `JsonLd.tsx` from the clone output.
4. We adapt the cloned copy/brand to your answers above.
5. `npm run check` (lint + typecheck + RSC audit + build) validates the result.
